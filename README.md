# TOEFL Writing Build a Sentence

托福句子构建练习系统。基于 2026 年新托福写作 Sentence Building 题型开发，内置 623 道 Build a Sentence 真题（含五维标签标注），支持按套题刷题、按语法点专项练习和错题管理。

题库版本：`bs625-20260922`

## 功能

- **练习模式**：题干模板挖空 + 选项词块拖点组句，提交后逐词判分并展示范答与解析
- **套题模式**：72 套真题按考试日期分组，还原完整套题作答流程
- **五维筛选**：按场景（20 类）、肯否定、句子功能、句子结构、语法点、交际目的交叉筛选，可精确到某个语法点的 4 道题
- **题库总表**：数据库样式的全题库表格视图，支持列头排序、六路筛选、关键词全文搜索（覆盖题干/范答/解析），点击任意行直接跳转练习
- **错题本**：自动收答错的题，按套题或语法点集中重练
- **学习统计**：按维度统计正确率与练习量

## 文件结构

```
├── index.html              # 页面结构与样式（约 52KB）
├── build-a-sentence-data.js # 题库数据：BANK_VERSION + EMBEDDED_BANK（623 题）
└── build-a-sentence-app.js  # 全部交互逻辑（练习/判分/筛选/统计/总表）
```

三个文件相互依赖，需放在同一目录。题库更新时只改 `build-a-sentence-data.js`，页面与逻辑无需变动。

## 使用方式

**本地使用**：解压后直接双击 `index.html` 用浏览器打开即可，无需安装任何东西。学习记录保存在浏览器 localStorage 中。

**部署到 GitHub Pages**：

1. 新建仓库（或使用现有仓库），将三个文件上传到仓库根目录
2. 仓库 Settings → Pages → Source 选择 `main` 分支
3. 等待约一分钟后访问 `https://<用户名>.github.io/<仓库名>/`

注意 `index.html` 是页面入口，GitHub Pages 默认从它开始加载，请勿改名。

## 题库说明

- 数据来源：新东方高级班讲义题库（Build a Sentence，源表 625 行，剔除 2 道损坏题）
- 每题含：题干模板、A–H 选项、答案、范答、中文解析，以及场景/肯否定/句子功能/句子结构/语法/交际目的六维标签
- 判分逻辑：按范答逐词比对（忽略大小写与标点），部分正确会按词计分
- 上传 Excel 自定义题库的功能保留在「题目管理」页，导入的题不影响内置题库

## 技术说明

纯静态页面，无构建步骤、无运行时依赖（页面内引用的 xlsx 库仅用于「题目管理」页解析用户上传的 Excel，离线使用不影响其他功能）。兼容现代浏览器（Chrome / Edge / Safari / Firefox）。
