# TOEFL Writing Build a Sentence

托福句子构建练习系统。基于 2026 年新托福写作 Sentence Building 题型开发，内置 **771 道** Build a Sentence 真题（覆盖 2026 年 1–9 月全部考试套题，按题干去重后的权威版本），含五维标签标注与难度分级，支持按套题刷题、按语法点专项练习、难度筛选和错题管理。

题库版本：`bs625-20261105v4.2`（771 题 / 130 套）

## 功能

- **练习模式**：题干模板挖空 + 选项词块点选组句，每题显示难度星标与来源套题徽章，提交后逐词判分并展示范答
- **套题模式**：130 套真题按考试日期分组（多卷共享题分别入套），还原完整套题作答流程，完成后弹成绩单与错题明细
- **六路筛选**：按场景（18 类）、肯否定、句子功能、句子结构、交际目的交叉筛选，再叠加**难度 1–5** 分级或关键词搜索，可精确到某个语法点的几道题
- **难度系统**：每题 1–5 星难度（源自教研标注），练习页星标展示、总表可按难度列排序、两处难度下拉筛选
- **题库总表**：数据库样式的全题库表格视图，支持列头排序、多路筛选、关键词全文搜索（覆盖题干/范答/来源），点击任意行直接跳转练习
- **错题本**：答错自动收录（带维度标注与累计错次），按套题或语法点集中重练，支持错因标记、状态管理与导出/导入
- **学习统计**：按维度统计正确率与练习量

## 文件结构

```
├── index.html               # 页面结构与样式（约 52KB）
├── build-a-sentence-data.js # 题库数据：BANK_VERSION + EMBEDDED_BANK（771 题，约 560KB）
└── build-a-sentence-app.js  # 全部交互逻辑（练习/判分/筛选/统计/总表/错题本）
```

三个文件相互依赖，需放在同一目录。题库更新时只改 `build-a-sentence-data.js`，页面与逻辑无需变动。

## 使用方式

**本地使用**：直接双击 `index.html` 用浏览器打开即可，无需安装任何东西。学习记录保存在浏览器 localStorage 中（不同设备/浏览器间不互通）。

**部署到 GitHub Pages**：

1. 新建仓库，将三个文件（连同本 README）上传到仓库根目录
2. 仓库 Settings → Pages → Source 选择 `main` 分支 / 根目录
3. 等待约一分钟后访问 `https://<用户名>.github.io/<仓库名>/`

注意 `index.html` 是页面入口，GitHub Pages 默认从它开始加载，请勿改名。

## 题库说明

- 数据来源：新东方高级班讲义题库 Build a Sentence 总表（去重合并版），覆盖 2026 年 1–9 月考试
- 每题含：题干模板、选项、答案语序、范答、来源套题（多卷复用题保留全部归属），以及场景/肯否定/句子功能/句子结构/交际目的五维标签 + 难度分级
- 难度格式已统一为整数 1–5（源表 ★ / · / 数字三种标注归一，未标注默认 3）
- 判分逻辑：按范答逐词比对（忽略大小写与标点），部分正确按词计分
- 上传 Excel 自定义题库的功能保留在「题目管理」页，导入的题不影响内置题库

## 技术说明

纯静态页面，无构建步骤、无运行时依赖（页面内引用的 xlsx 库仅用于「题目管理」页解析用户上传的 Excel，离线使用不影响其他功能）。兼容现代浏览器（Chrome / Edge / Safari / Firefox）。
